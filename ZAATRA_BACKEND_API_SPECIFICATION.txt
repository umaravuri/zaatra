1. AUTHENTICATION & MOBILE OTP FLOW
================================================================================

1.1 Direct Email/Password Login
Endpoint: POST http://localhost:5000/api/auth/login
Method: POST
Body:
{
  "email": "admin@zaatra.com",
  "password": "adminpassword123"
}

1.2 User / Customer Registration
Endpoint: POST http://localhost:5000/api/auth/register
Method: POST
Body:
{
  "name": "Ananya Sen",
  "email": "ananya@example.com",
  "password": "mysecretpassword123",
  "phone": "+91 98765 43210",
  "city": "Bengaluru",
  "state": "Karnataka",
  "country": "India",
  "role": "customer"
}

1.3 Mobile Number Login Step 1 (Request 6-Digit OTP)
Endpoint: POST http://localhost:5000/api/auth/mobile/login-init
Method: POST
Body:
{
  "phone": "+91 98765 43210",
  "password": "password123"
}
Response:
{
  "message": "OTP sent successfully to +91 98765 43210",
  "phone": "+91 98765 43210",
  "otp": "943545",
  "expiresInSeconds": 600
}

1.4 Verify 6-Digit OTP
Endpoint: POST http://localhost:5000/api/auth/mobile/verify-otp
Method: POST
Body:
{
  "phone": "+91 98765 43210",
  "otp": "943545"
}
Response:
{
  "message": "OTP verified successfully",
  "phone": "+91 98765 43210",
  "verified": true
}

1.5 Choose Role & Complete Login (Returns Token & User)
Endpoint: POST http://localhost:5000/api/auth/mobile/select-role
Method: POST
Body:
{
  "phone": "+91 98765 43210",
  "role": "customer"
}
Response:
{
  "message": "Role confirmed. Login successful!",
  "token": "eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9...",
  "user": {
    "id": "C-101",

    "email": "aarav@zaatra.com",
    "phone": "+91 98765 43210",
    "role": "customer",

    "avatar": ""
  }
}

2.4 Properties CRUD & Admin Approval Endpoints
- Get All Properties: GET http://localhost:5000/api/properties?type=Hotel&status=pending
- Get Single Property: GET http://localhost:5000/api/properties/:id (e.g. PR-1001)
- Update Property: PUT http://localhost:5000/api/properties/:id
- Delete Property: DELETE http://localhost:5000/api/properties/:id
- Admin Approval: PATCH http://localhost:5000/api/properties/:id/status
  Body: { "status": "listed" }
