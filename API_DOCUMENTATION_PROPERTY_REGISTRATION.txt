================================================================================
          ZAATRA BACKEND API SPECIFICATION: HOST PROPERTY REGISTRATION
================================================================================

Target Endpoint : POST /api/properties/register
Authentication  : Bearer <JWT_TOKEN> (Required in 'Authorization' header)
Content-Type    : application/json
Expected Role   : Host (or Admin)

--------------------------------------------------------------------------------
1. OVERVIEW & COMMON FIELDS (Required for ALL Property Types)
--------------------------------------------------------------------------------

Every property registration payload must include the following top-level fields:

Field Name       | Type    | Required | Description / Example
-----------------+---------+----------+-----------------------------------------
propertyName     | String  | YES      | e.g. "Palm Grove Beach Resort"
propertyType     | String  | YES      | Enum: "Resort" | "Villa" | "Farmhouse" | "Guest House" | "Hotel"
address          | Object  | YES      | Detailed location object (see below)
description      | String  | YES      | Detailed marketing & amenities narrative
houseRules       | Array   | YES      | List of rules (e.g. ["No Smoking", "No Pets", ...])
checkInCheckOut  | Object  | YES      | Check-in and check-out timings
photos           | Array   | YES      | List of uploaded image URLs / filenames
documents        | Object  | YES      | KYC and legal documents (see below)
pricing          | Object  | YES      | Pricing structure (varies by type)
propertyDetails  | Object  | YES      | Category-specific specifications (see below)
amenities        | Array/  | YES      | Array of strings (or object for Hotel)
                 | Object  |          |

--- Common 'address' Object Schema:
{
  "doorFlatNo": "D.No 4-56/A",                 // String (Required)
  "streetRoad": "Road No 2, Child Park Street",// String (Required)
  "landmark": "Near Axis Bank",               // String (Optional)
  "district": "Rangareddy",                   // String (Required)
  "city": "Hyderabad",                         // String (Required)
  "state": "Telangana",                       // String (Required)
  "pincode": "500081",                         // String (Required, 6-digit)
  "latitude": 17.4483,                        // Number (Optional / Geo)
  "longitude": 78.3915                        // Number (Optional / Geo)
}

--- Common 'checkInCheckOut' Object Schema:
{
  "checkInTime": "02 : 00 PM",                // String (Required, e.g. "14:00" or "02:00 PM")
  "checkOutTime": "11 : 00 AM"                // String (Required, e.g. "11:00" or "11:00 AM")
}

--- Common 'documents' Object Schema (KYC Attachments):
{
  "propertyOwnershipProof": "ownership_doc_01.pdf", // String (Required)
  "identityProof": "aadhaar_pan_01.pdf",            // String (Required)
  "taxRegistrationDocuments": "property_tax_01.pdf",// String (Required)
  "nocOtherDocuments": "noc_certificate_01.pdf"     // String (Optional)
}

2. CATEGORY-SPECIFIC SPECIFICATIONS
--------------------------------------------------------------------------------

================================================================================
CATEGORY A: RESORT
================================================================================
1. 'propertyDetails' Required Fields:
   - cottages     : (Integer) Number of individual cottages / suites (e.g. 12)
   - pools        : (Integer) Number of swimming pools (e.g. 2)
   - maxCapacity  : (Integer) Maximum total guest capacity (e.g. 60)
   - restaurants  : (Integer) Number of in-house dining/restaurants (e.g. 2)

2. 'amenities' Array:
   - ["Private Beach Access", "Swimming Pool", "Spa & Wellness", "Restaurant & Bar", "Kids Play Area", "Wi-Fi", "Parking", "Conference Hall", "Room Service", "Gym / Fitness Center"]

3. 'pricing' Object:
   - basePricePerNight               : (Number) Base rate per cottage/night (e.g. 8500)
   - guestPricePerExtraGuestPerNight : (Number) Fee per additional guest (e.g. 1500)
   - cleaningFee                     : (Number) Cleaning charges (e.g. 1000)
   - serviceFee                      : (Number) Resort maintenance fee (e.g. 500)
   - currency                        : (String) "INR"

CATEGORY C: FARMHOUSE
================================================================================
1. 'propertyDetails' Required Fields:
   - landArea      : (String) Total land/acreage measurement (e.g. "2.5 Acres" or "10,000 Sq.Ft")
   - bedrooms      : (Integer) Number of bedrooms in farmhouse building (e.g. 4)
   - bathrooms     : (Integer) Number of bathrooms (e.g. 4)
   - eventCapacity : (Integer) Maximum capacity for outdoor events/gatherings (e.g. 150)

2. 'amenities' Array:
   - ["Party Lawn & Stage", "Swimming Pool", "Open Gazebo", "Outdoor BBQ & Tandoor", "Campfire / Bonfire Pit", "Indoor Games (Table Tennis, Carrom)", "High-Power Music System", "Full Kitchen Setup", "Volleyball Court"]

3. 'pricing' Object:
   - basePricePerNight               : (Number) Nightly booking rate (e.g. 15000)
   - guestPricePerExtraGuestPerNight : (Number) Extra day-visitor charge (e.g. 800)
   - cleaningFee                     : (Number) Post-event cleaning charge (e.g. 2000)
   - serviceFee                      : (Number) Generator / security charge (e.g. 1000)
   - currency                        : (String) "INR"

================================================================================

   - sharedBaths   : (Integer) Common / shared bathrooms (e.g. 2)
   - maxGuests     : (Integer) Total maximum overnight guests (e.g. 16)

2. 'amenities' Array:
   - ["Wi-Fi", "Air Conditioning", "24/7 Hot Water", "Living Room Access", "Daily Housekeeping", "RO Drinking Water Purifier", "Breakfast Included", "CCTV Security", "Receptionist / Caretaker on Duty"]

   - basePricePerNight               : (Number) Base price per room or full house (e.g. 3500)
   - guestPricePerExtraGuestPerNight : (Number) Extra mattress / guest fee (e.g. 600)
   - cleaningFee                     : (Number) Room cleaning fee (e.g. 400)
   - serviceFee                      : (Number) Service fee (e.g. 200)

--------------------------------------------------------------------------------
3. EXPECTED BACKEND SUCCESS & ERROR RESPONSES
--------------------------------------------------------------------------------

--- Success Response (HTTP 201 Created / HTTP 200 OK):
{
  "success": true,
  "message": "Property submitted successfully and is pending admin review.",
  "data": {
    "propertyId": "PROP_68912401",
    "hostId": "HOST_55102",
    "propertyType": "Resort",
    "propertyName": "Palm Grove Beach Resort",
    "status": "PENDING_REVIEW",
    "createdAt": "2026-09-02T11:05:00.000Z"
  }
}

--- Validation Error Response (HTTP 400 Bad Request):
{
  "success": false,
  "message": "Validation Error: Missing required property details for Resort.",
  "errors": [
    "propertyDetails.cottages is required and must be an integer > 0",
    "propertyDetails.maxCapacity is required"
  ]
}

--- Unauthorized Error Response (HTTP 401 Unauthorized):
{
  "success": false,
  "message": "Invalid or expired authorization token."
}
